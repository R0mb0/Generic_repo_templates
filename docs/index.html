{ } Generic Repo Templates

Community health files, without the leftovers.

A small, generic set of files every open source repository should have — Code of Conduct, Contributing guide, Security policy, Support guide, and GitHub issue/PR templates. No project-specific assumptions baked in.

View on GitHub Download ZIP

What's inside

CODE_OF_CONDUCT.md

Standard Contributor Covenant 2.1 — works as-is for any project.

CONTRIBUTING.md

How to report bugs, suggest features, and submit code — generic guidance only.

SECURITY.md

Private vulnerability disclosure policy, so reports don't become public Issues.

SUPPORT.md

Where to get help — no false claims about who maintains the project.

ISSUE_TEMPLATE/bug_report.md

A single generic "Environment" field, no web/mobile-specific split.

ISSUE_TEMPLATE/feature_request.md

Standard problem/solution/alternatives structure.

PULL_REQUEST_TEMPLATE.md

A simple checklist, no embedded/firmware-specific fields.

How to use

  1. Copy the files into the root of your repository (issue and PR templates go into your own .github/ folder).
  2. Replace the contact email in SECURITY.md and CODE_OF_CONDUCT.md with your own.
  3. Done — no other adaptation needed.
